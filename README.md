# 💻 Laptop-Store - Online Laptop E-commerce Website

**Laptop-Store** is an e-commerce website project developed as a course assignment.  
It simulates a complete retail laptop system with full features for both **customers** and **administrators**.

---

## 🚀 Main Features

### 👨‍💻 Customer Interface
- **Homepage**: Displays featured products, promotional banners, and product categories.  
- **Product Listing**: View all products with advanced filters by brand, price range, and technical specifications.  
- **Product Details**: Full product information including images, description, specifications, and reviews.  
- **Product Comparison**: Compare specifications between multiple products.  
- **Shopping Cart**: Add, remove, update quantities, and place orders.  
- **User Authentication**: Register and log in to manage accounts.  
- **Account Management**: View order history, update personal information, and manage shipping addresses.  

### 🛠️ Admin Interface
- **Dashboard**: Business overview with charts and statistics.  
- **Product Management**: Full CRUD operations (Create, Read, Update, Delete) for products.  
- **Customer Management**: Manage registered customers and view their details.  
- **Employee Management**: Manage staff accounts.  
- **Supplier Management**: Manage supplier information.  
- **Order Management**: View and update customer order statuses.  
- **Promotion Management**: Create and manage discount campaigns.  
- **Inventory Management**: Manage stock entries (imports) and stock exits (sales).  

---

## 🏗️ System Architecture
- **Architecture Style**: Monolithic  
- **Communication**: RESTful API between Backend and Frontend  
- **Frontend Type**: Dynamic Web (HTML, CSS, JavaScript, Bootstrap)  
- **Backend**: Spring Boot application with security and database integration  

---
